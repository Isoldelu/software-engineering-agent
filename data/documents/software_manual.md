# Software Component Manual

## openssl

openssl provides TLS encryption capabilities for secure management and data-plane communication.

Main components:

- libssl.so
- libcrypto.so

## ethtool

ethtool is used to query and configure network interface parameters, including link status, speed, duplex mode, and driver information.

## nginx

nginx provides HTTP service capability in this simulated network device software environment.

Main components:

- nginx
- libhttp.so

## tcpdump

tcpdump is used for network packet capture and protocol-level traffic analysis.

Main components:

- tcpdump
- libpcap.so
